# SkyMaker!

**This tool creates custom Minecraft skies from a simple image.**

## HOW TO USE
- Join Discord for instructions: https://discord.com/invite/ExGSqUT6qk
- Video: https://www.youtube.com/watch?v=mXpquA15vxk


## Features
- Creates a custom Minecraft sky from a simple `.png` image.
- Automatically smooths the edges of images for a cleaner look. You can adjust how smooth the edges are using the "Smooth Edge Blend" setting.
