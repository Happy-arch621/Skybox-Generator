# SkyMaker!

**Esta herramienta crea cielos personalizados para Minecraft a partir de una imagen sencilla.**



## Como usarse!!
- Video: https://www.youtube.com/watch?v=mXpquA15vxk


## Características
- Crea un cielo customizado utilizando solamente una imagen .png
- Suaviza automáticamente los bordes de las imágenes para lograr un aspecto más limpio. Puedes ajustar el grado de suavizado de los bordes mediante la configuración "Ancho de fusión".
